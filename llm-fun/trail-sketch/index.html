    Drag a point to move it. Tap the line to add a point in between. Tap a point to rename it, delete it or switch how it is reached.

    Paste a hike description into a chat with Claude and ask for a route script, or write one yourself. Coordinates give the best result; bare place names are looked up on OpenStreetMap.

      Script format
      name:Route name
      start: / via: / end:A point, in walking order: Label @ lat, lon, lat, lon, or just a place name
      straight:A point reached in a straight line, for off-trail legs
      mode:trail or straight, the default for the points after it
      area:Added to place-name searches, e.g. San Jacinto Mountains, CA
      loop: yesReturn to the start at the end
      profile:hiking-mountain, trekking or shortest
      # …A comment, ignored

      Put a via point at every junction where the route changes trail, so the router follows the described trails rather than its own shortest line. You can also paste GPX or GeoJSON here.

      You can also drop a file onto the map. Tracks keep their exact shape; GPX routes with few points are re-snapped to trails.

      Maps: OpenTopoMap, OpenStreetMap, Esri, Waymarked Trails. Trail routing: BRouter (brouter.de). Elevation: Open-Meteo (Copernicus DEM, 90 m). Place search: Nominatim. Naismith time is 5 km/h plus an hour per 600 m of ascent. Your route, settings and script are saved in this browser. More LLM-built things.
